# 科研日志规范

`worklog/` 用于记录每天的科研推进情况。日志不需要写成流水账，重点记录今天推进了什么、得到什么结论、修改了哪些文件、遇到什么问题以及下一步怎么做。

## 命名规则

每天一个 Markdown 文件，文件名固定为：

```text
YYYY-MM-DD.md
```

例如：

```text
2026-09-15.md
```

## 推荐内容

- 今日任务：计划推进的核心事项。
- 今日完成：实际完成的工作。
- 关键结论：今天得到的模型理解、实验判断或文献结论。
- 修改/新增文件：便于和 Git commit 对应。
- 遇到的问题：记录卡点，方便后续回看。
- 下一步：下一次工作从哪里接上。

## 使用建议

每次提交前先更新当天日志，再执行 `git add .` 和 `git commit`。这样 Git 历史和科研日志能够互相对应。
